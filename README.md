# Окно – изјаве бирача (НПРС-3) са личне карте

Апликација за прикупљање потписа подршке изборној листи: бирач убаци личну карту у читач, Окно прочита податке са чипа
и одштампа попуњен образац НПРС-3 у потребном броју примерака, спреман за потпис и оверу. Свака штампа иде у евиденцију
из које се једним кликом добија списак бирача (образац НПРС-5, Excel) за РИК.

## Упутство

[Okno-uputstvo.pdf](https://github.com/lemara98/okno/releases/latest/download/Okno-uputstvo.pdf) – упутство за кориснике
са снимцима екрана (латиница).

## Пробна верзија и лиценца

Без кључа апликација ради као пробна верзија (један дан, до 25 штампи); демо картица и симулација штампе раде неограничено.
Лиценцни кључ важи за целу организацију, све рачунаре и локације, до краја изборног циклуса.

## Заштита података

Чува се само оно што РИК тражи у списку НПРС-5 (име, презиме, ЈМБГ, време, оверитељ). Адреса, фотографија и подаци о
личној карти се не чувају. Апликација ради без интернета и закључава се по завршетку изборног циклуса.
